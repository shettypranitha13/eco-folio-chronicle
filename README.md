# Eco Thrive Portfolio

Build a modern, responsive, and professional Environmental Studies E-Portfolio website for a college student. The website should have a clean eco-friendly theme using shades of green, white, blue, and earthy colors. Use smooth animations, rounded cards, subtle shadows, glassmorphism effects, and attractive icons. The website should be fully responsive for desktop, tablet, and mobile devices.

Website Title

Environmental Studies E-Portfolio

Navigation Bar

Include the following navigation links:

 Home

 About Me

 Subject Overview

 Assignments

 Portfolio Overview

 Contact

The navigation bar should remain fixed at the top while scrolling.

1. Home Page (Landing Page)

Create an attractive hero section with:

 Large title:
Environmental Studies E-Portfolio

 Subtitle:
Learning, Awareness, Sustainability & Environmental Responsibility

 A circular photo frame on the right side as a placeholder for my profile picture.

 On the left side include:

 Name placeholder

 Class

 Roll Number

 Department

 College Name

 Add a short welcome message introducing the portfolio.

 Add a "Explore Portfolio" button that smoothly scrolls to the next section.

 Background should include animated leaves, nature illustrations, mountains, trees, or soft environmental graphics.

2. About Me Page

Create a professional profile section.

Include:

Profile Card

Technical Requirements

 React + TypeScript

 Tailwind CSS

 Clean reusable components

 Responsive design

 SEO-friendly structure

 Fast loading

 Well-organized folder structure

 Easy-to-edit placeholders for text, images, assignments, and profile details

Overall Style

The website should look like a premium student portfolio rather than a basic college project. It should have a professional yet elegant appearance inspired by sustainability and nature, with subtle animations, engaging visuals, and a polished user experience suitable for presentation and evaluation by faculty.
